# Getting help with GrandNode

| You want to... | Go to |
| --- | --- |
| Ask a question, share an idea or show your project | [GitHub Discussions](https://github.com/grandnode/grandnode2/discussions) |
| Report a bug or request a feature | [GitHub Issues](https://github.com/grandnode/grandnode2/issues/new/choose) |
| Report a security vulnerability | [Private vulnerability report](https://github.com/grandnode/grandnode2/security/advisories/new) - see [SECURITY.md](SECURITY.md) |
| Install, configure or build GrandNode | [docs/installation.md](docs/installation.md), [docs/development.md](docs/development.md) and the [knowledgebase](https://grandnode.com/knowledgebase?utm_source=github&utm_medium=link&utm_campaign=support) |
| Get commercial help with an installation, upgrade or custom development | [GrandNode Official](https://grandnode.com/official?utm_source=github&utm_medium=link&utm_campaign=support) - LTS releases and support |
| Find themes and plugins | [Themes and layouts](https://grandnode.com/configuration-themes-layouts?utm_source=github&utm_medium=link&utm_campaign=support) and [plugins](https://grandnode.com/system-plugins?utm_source=github&utm_medium=link&utm_campaign=support) in the knowledgebase |

When you ask for help, include the GrandNode version, how you run it (Docker, Linux, Windows) and the exact
error message - it saves a round trip.
