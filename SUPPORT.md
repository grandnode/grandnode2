# Getting help with GrandNode

| You want to... | Go to |
| --- | --- |
| Ask a question, share an idea or show your project | [GitHub Discussions](https://github.com/grandnode/grandnode2/discussions) |
| Report a bug or request a feature | [GitHub Issues](https://github.com/grandnode/grandnode2/issues/new/choose) |
| Report a security vulnerability | [Private vulnerability report](https://github.com/grandnode/grandnode2/security/advisories/new) - see [SECURITY.md](SECURITY.md) |
| Install, configure or build GrandNode | [docs/installation.md](docs/installation.md), [docs/development.md](docs/development.md) and [docs.grandnode.com](https://docs.grandnode.com/?utm_source=github&utm_medium=link&utm_campaign=support) |
| Get commercial help with an installation, upgrade or custom development | [Premium support packages](https://grandnode.com/premium-support-packages/?utm_source=github&utm_medium=link&utm_campaign=support) |
| Find themes and plugins | [Themes](https://grandnode.com/grandnode-themes/?utm_source=github&utm_medium=link&utm_campaign=support) and [extensions](https://grandnode.com/extensions/?utm_source=github&utm_medium=link&utm_campaign=support) |

When you ask for help, include the GrandNode version, how you run it (Docker, Linux, Windows) and the exact
error message - it saves a round trip.
