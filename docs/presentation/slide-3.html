Objectifs Pédagogiques

  • Infrastructure as Code (IaC)

    Maîtrise de Terraform pour le déploiement automatisé et reproductible de l'infrastructure Cloud.

  • Kubernetes & Scalabilité

    Compréhension approfondie de l'auto-scaling (HPA, Cluster Autoscaler) et du load balancing sur Amazon EKS.

  • Monitoring & Observabilité

    Gestion proactive de la production avec CloudWatch, Prometheus et Grafana pour détecter les incidents.

  • Sécurité Cloud

    Implémentation d'une stratégie de sécurité "Defense in Depth" (IAM, Security Groups, WAF, Secrets).

  • FinOps & Optimisation

    Optimisation des coûts cloud et utilisation stratégique des Spot Instances pour respecter le budget.
